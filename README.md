# RANSAC Implementation

## Requirments

- Python 3
- NumPy
- Matplotlib

## Installation

Install the required libraries:

```bash
python3 -m pip install numpy matplotlib
```

## How to Run

Open a terminal in the folder containing `Ransac.py` and run:

```bash
python3 Ransac.py
```

## Output

The program prints the estimated slope, intercept, number of inliers and outliers, and iterations performed. It also displays a regression plot and saves it as `ransac_result.png`.
